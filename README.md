# pixelopenspace

Application macOS (Swift / SwiftUI / SpriteKit) qui représente les sessions Claude Code en cours sous la forme d'un open space isométrique en pixel art : un îlot par projet, un agent par session, des post-its pour les tâches.

**Statut : étape 2 (MVP sans graphismes) codée, démo à faire sur ton Mac.** Guides : [`docs/ETAPE-2A.md`](docs/ETAPE-2A.md) (agents, états, terminaux) et [`docs/ETAPE-2B.md`](docs/ETAPE-2B.md) (post-its, livraison gardée, relance). La proposition technique et design (architecture, modèle de données, intégration Claude Code, maquettes, sprites, plan de livraison) reste dans [`docs/PROPOSITION.md`](docs/PROPOSITION.md).
