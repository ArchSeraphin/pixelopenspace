# pixelopenspace

Application macOS (Swift / SwiftUI / SpriteKit) qui représente les sessions Claude Code en cours sous la forme d'un open space isométrique en pixel art : un îlot par projet, un agent par session, des post-its pour les tâches.

**Statut : étape 3 (l'open space isométrique) codée, checklist manuelle à passer sur ton Mac.** La scène SpriteKit remplace la liste des agents (toujours là par ⌘L) : caméra au pixel près, clic sur un agent pour sa fenêtre, double-clic pour son terminal, post-its glissés sur la scène, mini-carte et flèches de bord, arrivées par l'ascenseur. Guides : [`docs/ETAPE-2A.md`](docs/ETAPE-2A.md) (agents, états, terminaux), [`docs/ETAPE-2B.md`](docs/ETAPE-2B.md) (post-its, livraison gardée, relance), [`docs/jalon-visuel/README.md`](docs/jalon-visuel/README.md) (direction artistique, validée le 2026-10-01) et [`docs/ETAPE-3.md`](docs/ETAPE-3.md) (l'open space, le mode démo du protocole « 3 s », la checklist). Provenance des sprites et des polices : [`docs/ASSETS.md`](docs/ASSETS.md). La proposition technique et design (architecture, modèle de données, intégration Claude Code, maquettes, sprites, plan de livraison) reste dans [`docs/PROPOSITION.md`](docs/PROPOSITION.md).

Prochaine étape : l'étape 4 (finitions visuelles : mode nuit, remplacement des sprites par tes PNG, fenêtres rétro, polices, sons, icône).
