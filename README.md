# pixelopenspace

Application macOS (Swift / SwiftUI / SpriteKit) qui représente les sessions Claude Code en cours sous la forme d'un open space isométrique en pixel art : un îlot par projet, un agent par session, des post-its pour les tâches.

**Statut : étape 1, proposition à valider.** Lire [`docs/PROPOSITION.md`](docs/PROPOSITION.md) : architecture, modèle de données, intégration Claude Code vérifiée dans la doc officielle, maquettes ASCII, liste des sprites et plan de livraison. Aucun code de l'app n'est écrit avant validation.
